# Child Safety Monitor 🚨

A context-aware AI system for monitoring child safety using:
- YOLOv8 (person detection)
- Pose estimation
- Audio analysis
- Context reasoning

## Features (WIP)
- Real-time person detection
- Child vs adult classification
- Pose-based danger detection (coming soon)

## Tech Stack
- Python
- OpenCV
- PyTorch
- YOLOv8
